# 诊断台 · 部署说明

本项目的 CloudStudio **一键部署工具只支持纯静态站点**，无法运行 Python 后端。
因此有两种上线方式，按需选择：

---

## 方式 A：静态只读快照（推荐，已上线 ✅）

**适用**：让别人"随时可看"大盘（浏览客户、趋势、归因、已生成的报告）。
**特点**：零额外机器、云端持久托管、**你 Mac 关机别人也能看**；但**只读**——生成新报告 / 审核入库仍需在本地后端做，做完重新导出快照并重新部署即可。

### 原理
前端 `web/app.js` 检测到后端 API 不可达时，会自动回退读取 `web/snapshot.json`（一份预先算好的静态数据：50 客户 + 日度序列 + 归因 + 已生成报告），因此整套可作为纯静态站点托管。

### 步骤
1. 导出快照（零成本，不调 LLM）：
   ```bash
   cd 诊断台
   python3 static_export.py        # 生成 web/snapshot.json
   ```
2. 用 CloudStudio 静态部署把 `诊断台/web/` 目录发布：
   - 该目录含 `index.html` + `app.js` + `snapshot.json`，部署后即为只读大盘。
   - 线上链接示例：`https://349a08f059e14b86937b3346fa9a6d15.app.workbuddy.link`
3. 之后数据有更新（新生成报告等）：重跑 `static_export.py` → 重新部署同一目录即可。

### 注意
- `web/snapshot.json` 是生成产物，已被 `.gitignore` 忽略，不要提交；部署前务必本地先生成。
- 静态托管下「手动录入」视图自动隐藏，「生成报告」按钮变为「查看报告（静态快照）」。

---

## 方式 B：全功能实时后端（需额外主机）

**适用**：别人也要在线实时生成报告 / 审核入库。
**特点**：需要一台**持续运行、能跑 Python3 的主机**（Cloud Studio 工作空间 或 你自己的 VPS），CloudStudio 静态部署**覆盖不了**这部分。

### 环境要求
- Python 3.8+（**零第三方依赖**，标准库即可，无需 `pip install`）
- 一个 DeepSeek API Key（用于生成诊断报告）

### 步骤
1. 把整个 `诊断台/` 目录（**含 `data/` 数据库**，否则丢失案例库与模拟数据）传到主机。
2. 设置密钥并启动：
   ```bash
   export DEEPSEEK_API_KEY=sk-xxxxx
   ./start.sh                            # 或：python3 api_server.py --host 0.0.0.0 --port 8000
   ```
3. 打开 `http://<主机地址>:8000`。

### 配置项
| 项 | 默认值 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | 无（必填） | DeepSeek API Key，`llm.py` 直连调用 |
| `--host` | `127.0.0.1`（脚本里改 `0.0.0.0`） | 远程访问必须 `0.0.0.0` |
| `--port` | `8000` | 可用 `PORT=9000 ./start.sh` 覆盖 |

### 关于"一直在线"
- `start.sh` 内置 `while true` 崩溃自重启循环，挡住**进程自身崩溃**。
- 但挡不住**宿主机把整个环境回收**（如本地沙箱空闲回收后台任务）。要真·常驻，必须跑在**持续运行**的云工作空间或服务器上。

## 数据说明
- 数据库：`data/ad_review.db`（SQLite），含全部客户、报告、已沉淀的 **20 条 RAG 案例库**、11 个去重客户。`data/` 被 `.gitignore` 忽略，部署/拷贝时务必**连同 `data/` 一起**。
- 报告分享页落盘在 `web/reports/`（已被 `.gitignore` 忽略）。

## 关停
- 方式 B：`Ctrl+C` 停掉 `start.sh`。
- 方式 A：在 CloudStudio 发布管理里下线分享链接即可。
