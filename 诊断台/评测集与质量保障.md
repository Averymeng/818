# 评测集与质量保障（aipm-eval 框架）

> 本文档用 aipm-eval 框架整理诊断台 MVP 的评测体系。原始材料见 [`eval/`](eval)：`E01-E17_评测集设计稿.md`、`eval_report.md`、`judge_prompt.md`、`judge_calibration_report.md`、自动化 `run_eval.py` 与 CI。
> 设计底稿：[`AIPM_项目底稿.md`](AIPM_项目底稿.md) §C。

---

## 1. 评测对象（评什么）

对应 aipm-eval 的"评测对象"定义，覆盖**链路节点**与**端到端**两层：

- **链路节点**
  - 数据完整性判断是否正确（缺失/口径冲突显式提示、样本不足不强行归因）。
  - 各投放层级（账户/版位/计划/素材/转化漏斗）是否完整覆盖，异常对象是否正确识别。
  - 下钻路径是否合理（先串联漏斗定位环节，再并联拆对象）；工具调用是否必要且结果被正确使用。
  - 原因判断是否有证据；是否把"假设"错误表述为"事实"。
  - 历史案例是否真正相关；差异比较（相似点/关键差异）是否准确。
  - 建议是否具体、可执行、与诊断一致且风险可控。
  - 报告结构是否完整；人工修改/驳回是否能正确记录与回流。
- **端到端**：正常 / 单点异常 / 复合异常 / 指标冲突 / 数据缺失 五类场景可端到端跑通。

---

## 2. 评测集（用什么测）

- **规模**：17 个主用例（E01–E17，含 E11 拆 a/b、E01b 计入），自动化执行 **126 条断言，全部通过（126/126）**。
- **场景覆盖（MECE）**
  - 正常场景（基线表现稳定）
  - 单点异常（单一指标/单环节异常）
  - 复合异常（多环节叠加）
  - 指标冲突（指标间方向矛盾，检验"事实/推断"分离）
  - 数据缺失（缺字段/样本不足，检验降级与"待验证"输出）
- **真跑成本**：首轮真跑 LLM 约 ¥0.79（单 DeepSeek，约 30 次调用），体现零依赖低成本。

---

## 3. 评分标准（怎么判）

两层 rubric（MECE 分层）：
- **A 层 · 硬断言（确定性）**：对输出结构/字段/硬规则做程序化断言（如案例引用必须 `referenceable=1` 且非 badcase、证据必须引用数据字段、不出现后链路词汇越界）。
- **B 层 · LLM-as-judge（定性）**：对"原因合理性/建议可执行性/差异判断准确性"等无法硬判的项，用校准过的 `judge_prompt` 评分。

**校准**：`judge_calibration_report.md` 记录人评与 judge 的一致性对齐过程，确保软判断可用。

---

## 4. 自动化与回归

- **执行**：`eval/run_eval.py` 加载固定模拟数据快照，逐用例跑 Agent 并断言，产出 `eval/artifacts/eval_results.json`（passed=126 / total=126）。
- **CI**：`.github/workflows/eval.yml` 在每次推送回归，保证"改代码不破链路"。
- **可复现性**：模拟数据按日期派生种子、持久化，禁止临时随机——同一快照可重复运行、比较不同 Agent 版本。

---

## 5. Badcase 与迭代闭环

aipm-eval 要求的"低分→定位节点→修复→复测"闭环已在项目中落地：

- **召回类（已修复 2 类）**
  1. 中英签名漏匹配：`open_cost/lead_cost` 入库归一化为中文、召回用原始英文 LIKE 对不上 → 抽唯一映射 `SIG_MAP_EN2CN` 并查询前归一化。
  2. AND 过严导致空召回：原"行业+赛道+签名"同时命中才召回，同赛道不同行业客户第6章空白 → 放宽为"赛道命中即可"。
- **评测待修复项（3 项，均不涉及硬断言）**：如案例参考章节未展示相似点/关键差异、个别 note 文案与事实矛盾等，已登记修复方案。
- **红线修复示例**：E14 建议 risk 字段出现"ROI"措辞越界 → 在 prompt 补后链路词汇红线，复跑 0 处越界。

## 6. 项目表达边界（必须守住）

- ✅ 可写：评测设计（对象/MECE rubric/LLM-as-judge/CI）、Badcase 闭环、126/126 结果、零成本真跑。
- ❌ 不可写：把"断言通过数"说成"用户量/业务指标"；把模拟数据说成生产数据；夸大上线范围。
- 数据为**可复现模拟数据**（51 客户 / 66 报告），非真实客户数据；产品为 MVP Demo，未接入真实广告平台。
